# Repos cloned on every machine by ./clone-repos.sh (into ~/Code by default).
# A repo is a full clone URL — ssh or https, either works (cloning is
# ssh-first regardless, with an https fallback):
#
#   git@github.com:owner/repo.git
#   https://github.com/owner/repo
#
# Any line that is NOT a URL names a directory; repos indented under it
# clone there, and directories nest by indenting. ~/… and absolute paths
# root their own tree:
#
#   git@github.com:cli/cli.git             -> ~/Code/cli
#   work
#     git@github.com:acme/api.git          -> ~/Code/work/api
#     clients
#       https://github.com/acme/webapp     -> ~/Code/work/clients/webapp
#   ~/somewhere
#     git@github.com:owner/other.git       -> ~/somewhere/other
#
# Trailing "# comments" are fine too. Full format: bin/outline --help.
# Machine-specific repos go in repos/<profile>.txt instead (same profile
# names as the Brewfile.<name> files).
